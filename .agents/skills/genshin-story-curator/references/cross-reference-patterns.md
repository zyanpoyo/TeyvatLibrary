## 1. 代名詞・伏せ字のクロスリファレンス特定パターン

原神の装備・書籍テキストでは、主要人物ほど名前が伏せられる。以下の5つの照合パターンを使って公式根拠から正体を特定する。

### パターンA: 聖遺物 × 週ボス育成素材（最も確実な実名根拠）
- **仕組み**: 聖遺物では「少女」「魔女」「傾奇者」としか書かれないが、対応する週ボスのドロップ素材（★5育成素材）には本名や二つ名が明記される。
- **実例**:
  - 聖遺物『燃え盛る炎の魔女』の「燃える魔女がまだ少女」× 週ボス淑女素材『溶滅の刻』『獄炎の蝶』『灰燼の心』 → **ロザリン・クルーズチカ・ローエファルタ（ファデュイ執行官第八位『淑女』）**

### パターンB: 聖遺物の「要石（かなめいし）部位」からの逆算
- **仕組み**: 5部位のうち4部位では全員が代名詞で書かれていても、1部位（多くは「理の冠」または「時の砂」）にだけ勧誘者や語り手の実名が明記されている。
- **実例**:
  - 聖遺物『蒼白の炎』の理の冠『嗤笑の面』にある「我が名は『道化』のピエロ」を起点に、他4部位に登場する「一人目の愚者」＝ **道化（ピエロ）** と確定。
  - さらに各部位の特徴（液体の炎＝**淑女**、教令院から追放され人間を機械と呼ぶ少年＝**博士／ザンディク**、神の目を持たず金銭の心臓を握る＝**富者／パンタローネ**、眠りから目覚めた神造の人形＝**散兵／スカラマシュ**）を特定。

### パターンC: 対になる武器 × 聖遺物の相互照合（贈り物・詩・固有名詞の一致）
- **仕組み**: 聖遺物側で「ある人からもらった〇〇」と書かれ、同シリーズの武器側に「〇〇を贈った騎士／戦友の実名」が書かれているケース。
- **実例**:
  - 『燃え盛る炎の魔女（時の砂）』の「時計をくれた人」× 弓『終焉を嘆く詩』の「遠方に留学した彼女を想いながら戦死した騎士（戦友エレンドリン・ローランドの名が登場）」× 聖遺物『守護の心』× 武器『西風剣』 → **西風騎士団の騎士ルースタン**（「幼い狼」）

### パターンD: 書籍の「禁書・付録・暗号表記」の解読
- **仕組み**: 書籍内で検閲や禁忌を避けるために使われた逆さ書き・改名対照表を解読する。
- **実例**:
  - 『白夜国館蔵（第2巻：日月前事）』の「一回だけ、あえて逆に書こう——『トロタスイ』」 → 逆さ読みで **イスタロト（時間の執政／常世大神カイロス）**。
  - 『白夜国館蔵（第5巻：光昼影底集）』の巻末付録にあるギリシャ名と鳴神名の対照表（`アブラクサス - 阿倍良久`、`スパルタクス - 須婆達`、`エレボス - 烏帽子`）を使って、第1〜3巻と武器『誓いの明瞳』の登場人物を同一人物として紐付ける。

### パターンE: 書籍 × 武器 × 突破素材の「事件連鎖」照合
- **仕組み**: 書籍に「原因（事件・禁忌）」が書かれ、武器に「当事者の宣誓・決断」が書かれ、突破素材に「結末（死の真相）」が書かれる三部作構造。
- **実例**:
  1. **原因（書籍『日月前事』）**: 天理（原初のあの方）が外来の侵略者であるという禁忌の記録。
  2. **決断（法器『誓いの明瞳』）**: 淵下宮の民と盟約を結んだ白蛇オロバシが、最後に「天の都との誓いを果たす時が訪れた」と地上へ向かう。
  3. **結末（突破素材『遠海夷地の珊瑚枝』）**: オロバシが民を地上へ逃がすために珊瑚の梯子を作り、自ら「踏み入れてはならない土地」へ入って「敵わぬ敵（雷電将軍）」に斬り伏せられた自己犠牲の真相。

## 2. 現行編集層ストーリーJSONテンプレート（`data/stories/<shelfCategory>/<id>.json`）

- 文字列の `readingTime` や `charCount`、`evidenceLinks`、逆方向の `connected` は `npm run build:data` が自動計算するため、編集層JSONには書かない。
- 配置フォルダと `shelfCategory`、ファイル名と `id` は必ず一致させる。

```json
{
  "$schema": "../../schemas/story.schema.json",
  "id": "unique_story_slug",
  "title": "作品タイトル（原典名または連作タイトル）",
  "shelfCategory": "book | artifact | weapon | attire | chronicle",
  "categoryLabel": "書籍（古文書・禁書） | 聖遺物（連作短編） | 武器（短編小説） | 風の翼（短編・銘文） | 育成素材（週ボス素材連作） | 突破素材（四幕詩）",
  "region": ["モンド"],
  "era": "500年前の災厄",
  "addedAt": "YYYY-MM-DD",
  "hook": "ライトユーザーが思わず読みたくなる1行キャッチコピー",
  "tags": ["関連キャラ名", "時代・キーワード", "構成の特徴"],
  "preGuide": [
    "舞台：いつの時代・どこの場所の話か（ネタバレなし）",
    "主人公：誰（どのような立場の人物）の視点か",
    "読みどころ：どう読むと分かりやすいか（時系列順の再構成など）"
  ],
  "overallTruth": "読了後にのみ開示する種明かし・考察メモ（誰の物語だったのか、他作品とどう繋がるか）",
  "gameEffect": "ゲーム内のアイテム種別・レア度・セット効果や入手条件",
  "connected": [
    {
      "targetId": "target_story_id",
      "relation": "この作品から見た関係性の見出し",
      "desc": "『対象作品名』——どういう繋がりがあるかの1行説明",
      "reverseRelation": "相手作品からこの作品へ自動で張られる逆リンク見出し",
      "reverseDesc": "『この作品名』——相手作品側で表示される逆リンク説明"
    }
  ],
  "glossary": {
    "master_linked_term": {
      "entityId": "rustan",
      "term": "原文中でハイライトした語句",
      "descOverride": "この物語の文脈に合わせた補足（任意）",
      "evidenceOverride": "聖遺物『守護の心』（守護の座時計）・武器『終焉を嘆く詩』"
    },
    "local_term": {
      "term": "作品固有の語句",
      "identity": "解説：必ず 正体：/真名：/鳴神名：/解説：/有力説： のいずれかで始める",
      "desc": "ライトユーザー向けの背景解説（一般カタカナ語は原則和語・漢字で記述）",
      "evidence": "裏付けとなる公式記録名（『作品名』をそのまま囲むと自動リンク化）"
    }

    {
      "sourceRef": {
        "package": "genshin-db",
        "sourceType": "artifact | weapon | windglider | material | book",
        "rawId": "raw_filename_without_ext"
      },
      "partLabel": "第一章（元の部位名・巻名・素材名）",
      "heading": "その章の内容を表す小説風の小見出し",

        "段落テキスト1。段落内の単一改行は \\n で保持し、原典の空行 \\n\\n で配列要素を分ける（原典の誤字・旧字体も無改変で保持）。",
        "段落テキスト2。注釈対象語句は {{master_linked_term|原文そのままの文字列}} で囲む。"
      ],
      "chapterNote": "（任意）章末に添える1行の読解ヒント"
    }
  ]
}
```

### `sourceRef` の種別ごとの追加指定例
- **聖遺物 (`artifact`)**: `"piece": "flower" | "plume" | "sands" | "goblet" | "circlet"` を必須指定。
- **突破・育成素材 (`material`)**: `"field": "description"` と、冒頭定型文を除く `"stripPrefix": "武器に突破の力を付与する材料。\n"` 等を指定（同シリーズ内の文言ゆらぎに注意）。
- **書籍 (`book`)**: `"package": "yatta"`（または `"genshin-data"`）、`"volumeId": 101681`、`"field": "text"` を指定し、分割時は `"paragraphSlice": [0, 9]` を指定。

## 3. 原文完全一致・正規化チェックの仕組み

[`scripts/lib/validator.mjs`](../../../../scripts/lib/validator.mjs) は以下を照合し、1文字でも不一致があれば Exit 1 とする。

1. `data/raw/<sourceType>/<rawId>.json` から対象フィールドを取得し、`<br/>` → `\n`、`<color>` / `<span>` タグ除去を実施。
2. `sourceRef.stripPrefix` が指定されていれば先頭から完全一致で除去し、`sourceRef.paragraphSlice` があれば段落スライスを適用。
3. 編集層 `chapters[].paragraphs` から `{{term_id|表示文字列}}` を剥がして `\n\n` で結合した文字列と、手順2の結果が空白正規化後に100%一致することを検証する（原典の誤字・旧字体および `{M#...}{F#...}` 等の性別分岐記法も無改変のまま比較し、性別分岐は描画時のみフロントエンドが可読展開する）。
