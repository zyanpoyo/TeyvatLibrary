# 0002: 3層データ分離とビルド時の原文1文字完全一致検証

ストーリーデータは「①原典層（`data/raw/`）」「②編集層（`data/stories/`, `data/shared/`）」「③配信層（`public/data/`）」の3層に分離し、ビルド時に装飾タグ正規化・宣言的スライス適用後の原典文字列と、編集層本文から注釈タグ `{{term_id|...}}` を除去した文字列が1文字の狂いもなく一致することを機械検証する。

## Considered Options

- **3層分離 ＋ ビルド時1文字完全一致検証（採用）**: 公式原文への無断改変・脱字・表記揺れ混入をビルドゲートで確実に遮断しつつ、編集層で自由に章順再構成や用語ガイド付与を行える。
- **編集済みテキストを単一JSONで直接管理**: 管理ファイル数は減るが、原文と編集文の乖離を機械検証できず、ファンアーカイブとしての原典忠実性を保証できない。

## Consequences

- 編集データ側のテキスト整形（誤字修正や勝手な送り仮名改変）は禁止され、定型文除去や抜粋が必要な場合は `sourceRef` の `stripPrefix` / `paragraphSlice` による宣言的指定を用いる。
- 配信層（`public/data/`）は生成物として `.gitignore` 除外し、Git 管理は原典層と編集層のみを対象とする。
