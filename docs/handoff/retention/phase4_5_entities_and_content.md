# Phase 4 & 5 詳細仕様：「人物・用語名鑑」ビュー＆収録作品の継続拡充

本仕様は、人物・用語マスタ（[`data/shared/entities.json`](../../../data/shared/entities.json)）を設定確認辞書として活用する **Phase 4（人物・用語名鑑ビュー）** と、機能実装後のコンテンツ拡充指針である **Phase 5（作品追加の優先順位）** を定義する。

---

## Phase 4: 「人物・用語名鑑（Entities Archive）」ビューの独立

### 4.1 インデックス出力の拡張（`scripts/build-stories.mjs`）
- 現在 `public/data/stories-index.json` の `entitiesIndex` には `{ name, kind, storyIds }` のみが出力されている。
- ここに [`data/shared/entities.json`](../../../data/shared/entities.json) の `defaultIdentity`・`defaultDesc`・`defaultEvidence`・`evidenceLinks`（ビルド時自動解決）を含めて出力する。

### 4.2 人物・用語名鑑ビューUIの実装（`src/router/routes.tsx`, `src/components/entities/` 等を新設して統合）
- 書架上部のナビゲーションまたはタブから切り替えられる「人物・用語名鑑」ビュー（またはドロワー／モーダル）を追加する。
- 種別（`character`: 人物 / `god`: 魔神・執政 / `organization`: 組織 / `concept`: 歴史・重要用語 / `place`: 地域・地名）でグルーピングまたは絞り込み表示する。
- 各エンティティカードには以下を表示する:
  - 名称（`name`）と正体（`defaultIdentity`）
  - 背景解説（`defaultDesc`）と出典リンク（`defaultEvidence`）
  - **登場する物語リスト（`storyIds`）**: 作品タイトル・カテゴリー・読了バッジ（`✦ 読了`）を表示し、クリックで該当作品のリーダー画面へ直接遷移する。

### 4.3 Phase 4 完了条件（Completion Criteria）
- [ ] `entities.json` に登録された全エンティティの解説と出典リンク、および関連作品リストが人物・用語名鑑ビューから閲覧できること。
- [ ] 人物・用語名鑑内の関連作品リンクおよび出典リンク（`evidenceLinks`）をクリックすると、該当作品のリーダー画面へ遷移すること。

---

## Phase 5: 収録作品の継続拡充（コンテンツ密度の向上）

機能が揃った段階で、初回訪問での読み尽くしを防ぎ書店フェア棚・人物名鑑の網羅性を高めるため、[`.agents/skills/genshin-story-curator/SKILL.md`](../../../.agents/skills/genshin-story-curator/SKILL.md) のワークフローに従って以下の優先順位で作品を追加する。

1. **「風の翼（`attire`）」カテゴリーの0件解消（最優先・第1バッチ完了）**:
   - `npm run extract-raw -- --type windglider --id <rawId>` を使用し、長文ストーリーを持つ風の翼3作品（『交錯する運命の翼』『夜来泊月の翼』『樹花爛漫の翼』）を追加して全5分類タブすべてに作品を揃えた。今後も『蒼星の冬の翼』『余暇の翼』等の拡充を継続する。
2. **既存コース・書店フェア棚の拡充とミッシングリンク補完**:
   - **キャラ別過去セットの拡充**: 第1バッチとしてロザリン関連の完結編となる週ボス育成素材3種連作（『灰燼の心』『獄炎の蝶』『溶滅の刻』＝ `signora_chronicle`）・聖遺物『守護の心』、および八重神子・放浪者関連の武器『神楽の真意』を追加済み。さらに第3バッチとしてファデュイ執行官（召使アルレッキーノ・公子タルタリヤ・壁炉の家・赤月王朝）関連4作品（書籍『ペリンヘリ（全二巻）』、武器『赤月のシルエット』・『冬極の白星』、育成素材『残火の灯燭と赤月の裁決（召使討伐録）』）および主要2エンティティを追加収録し、コース①の収録ラインナップを拡充した。今後はスメール砂漠の長編聖遺物『砂上の楼閣の史話』や、ヴァネッサ（『風鷹剣』）・アンドリアス（『凛風奔狼』連作／『氷風を彷徨う勇士』）等を順次追加し、キャラ別フェア棚と Phase 4 の人物名鑑の厚みを増す。
   - **大型テーマまとめ棚の整備**: 第2バッチとしてフォンテーヌ「水仙十字院」関連6作品（聖遺物『水仙の夢』・『ファントムハンター』、武器『サーンドルの渡し守』・『超越の鍵』・『ルミドゥースの挽歌』・『久遠流転の大典』）および主要10エンティティを追加収録し、フォンテーヌ0件を解消した（※`genshin-db` 上で『静水流転の輝き』は長文本文0文字、『水仙十字の剣』は93文字であることを確認済み）。また第4バッチとしてコース③「テイワット創世記」関連4作品（書籍『竹林月夜（全四巻）』『白姫と六人の小人（全七巻）』、聖遺物『深廊の終曲』『黒曜の秘典』）および主要6エンティティ（月の三姉妹・兹白・スカーク・原初の龍ニーベルンゲン・盗炎の賢者・シュバランケ）を追加収録し、3大フェア棚の収録ラインナップをすべて揃えた。さらに第5バッチとしてスネージナヤ最新実装の6作品（聖遺物『影に沈む幻』『炉炎溶錬の心』『紅血の証』、書籍『スネージナヤ通史（全二巻）』『スネージナヤ通史補編（全三巻）』『蒼星フェイ史略』）および主要6エンティティ（ツァーリ・ベールイ＝モノマフ、アクシーニャ、雄鶏プルチネッラ、隊長カピターノ、アルヴィス大公、イズマイール＋氷の女皇アナスターシャ本名反映）を追加収録し、全35作品・45エンティティへ拡充した。今後は他地域の大型テーマ（スメール砂漠・レムリア・稲妻鶴観等）を順次収録し、Phase 3（[`phase3_curation_courses.md`](phase3_curation_courses.md)）の `courses.json` に新規フェア棚として統合する。
