# Phase 4 & 5 詳細仕様：「人物・用語名鑑」ビュー＆収録作品の継続拡充

本仕様は、人物・用語マスタ（[`data/shared/entities.json`](../../../data/shared/entities.json)）を設定確認辞書として活用する **Phase 4（人物・用語名鑑ビュー）** と、機能実装後のコンテンツ拡充指針である **Phase 5（作品追加の優先順位）** を定義する。

---

## Phase 4: 「人物・用語名鑑（Entities Archive）」ビューの独立（実装済み）

### 4.1 インデックス出力と検証の拡張（`scripts/lib/story-compiler.mjs` / `scripts/build-stories.mjs`）
- `public/data/stories-index.json` の `entitiesIndex` に、従来の `{ name, kind, storyIds }` に加えて [`data/shared/entities.json`](../../../data/shared/entities.json) 由来の `defaultIdentity`・`defaultDesc`・`defaultEvidence`・解決済み `evidenceLinks` を出力し、`verifyEntitiesIndex` で必須項目とリンク先実在性を検証する。

### 4.2 人物・用語名鑑ビューUI・SSG・SEO・クロスリンクの実装（`src/domain/entities.ts`, `src/components/entities/`, `src/routes/entities*.tsx`）
- **2階層ルート構成（[ADR-0006](../../adr/0006-ssg-framework-and-url-architecture.md) 準拠）**: 一覧ページ（`/entities`）および個別詳細ページ（`/entities/:entityId`）を SSG プリレンダリング＋`sitemap.xml`＋JSON-LD＋静的 OGP PNG（`/og/entities.png`・`/og/entity/<id>.png`）＋GA4 計測付きで構築。
- **一覧ページ（`/entities`）**:
  - 冒頭に「物語の核心・正体に関する記述を含みます」の注記を表示。
  - 種別フィルタ（`character` / `god` / `organization` / `concept` / `place` のうち収録 1 件以上ある種別のみ自動表示）、日本語正規化キーワード絞り込み、並び替え（登場作品数順／五十音順）、種別ごとのグループ一覧を実装。
- **個別詳細ページ（`/entities/:entityId`）**:
  - 名称・種別・正体（`defaultIdentity`）・背景解説全文（`defaultDesc`）・出典＆自動解決出典リンク（[`EvidenceText.tsx`](../../../src/components/common/EvidenceText.tsx)）を表示。
  - 登場物語リスト（カテゴリー・読了バッジ `✦ 読了`・`次に読む` バッジ）・読了進捗バー＆未読 CTA・関連する読書コース・同じ物語に登場する共起エンティティ・SNS シェアバー（`ShareBar`）を実装。
- **他画面からの4クロスリンク導線**: 常設ナビ（[`SiteNavBar.tsx`](../../../src/components/layout/SiteNavBar.tsx)＋フッター）、リーダー用語ガイド（[`GlossaryDialog.tsx`](../../../src/components/reader/GlossaryDialog.tsx)）、リーダー真相メモ内チップ（[`ReaderArticle.tsx`](../../../src/components/reader/ReaderArticle.tsx)）、書架の人物絞り込み中リンク（[`ShelfToolbar.tsx`](../../../src/components/shelf/ShelfToolbar.tsx)）を接続。

### 4.3 Phase 4 完了条件（Completion Criteria）
- [x] `entities.json` に登録された全エンティティの解説と出典リンク、および関連作品リストが人物・用語名鑑ビュー（`/entities`・`/entities/:entityId`）から閲覧できること。
- [x] 人物・用語名鑑内の関連作品リンクおよび出典リンク（`evidenceLinks`）をクリックすると、該当作品のリーダー画面へ遷移すること。
- [x] 組織・勢力（`organization`）・概念・法則（`concept`）・場所・古代文明（`place`）の主要エンティティ（28 件追加、5 種別計 86 件）を既存作品と接続し、書架 `#entity-filter` の 5 種別 `<optgroup>` グルーピングおよび検証／キュレーション規約（`entity-curation-guide.md`）を整備済みであること。

## Phase 5: 収録作品の継続拡充（コンテンツ密度の向上）

機能が揃った段階で、初回訪問での読み尽くしを防ぎ書店フェア棚・人物名鑑の網羅性を高めるため、[`.agents/skills/genshin-story-curator/SKILL.md`](../../../.agents/skills/genshin-story-curator/SKILL.md) のワークフローに従って以下の優先順位で作品を追加する。

1. **「風の翼（`attire`）」カテゴリーの0件解消（最優先・第1バッチ完了）**:
   - `npm run extract-raw -- --type windglider --id <rawId>` を使用し、長文ストーリーを持つ風の翼3作品（『交錯する運命の翼』『夜来泊月の翼』『樹花爛漫の翼』）を追加して全5分類タブすべてに作品を揃えた。今後も『蒼星の冬の翼』『余暇の翼』等の拡充を継続する。
2. **既存コース・書店フェア棚の拡充とミッシングリンク補完**:
   - **キャラ別過去セットの拡充**: 第1バッチとしてロザリン関連の完結編となる週ボス育成素材3種連作（『灰燼の心』『獄炎の蝶』『溶滅の刻』＝ `signora_chronicle`）・聖遺物『守護の心』、および八重神子・放浪者関連の武器『神楽の真意』を追加済み。さらに第3バッチとしてファデュイ執行官（召使アルレッキーノ・公子タルタリヤ・壁炉の家・赤月王朝）関連4作品（書籍『ペリンヘリ（全二巻）』、武器『赤月のシルエット』・『冬極の白星』、育成素材『残火の灯燭と赤月の裁決（召使討伐録）』）および主要2エンティティを追加収録し、コース①の収録ラインナップを拡充した。今後はヴァネッサ（『風鷹剣』）・アンドリアス（『凛風奔狼』連作／『氷風を彷徨う勇士』）等を順次追加し、キャラ別フェア棚と Phase 4 の人物名鑑の厚みを増す。
   - **大型テーマまとめ棚の整備**: 第2バッチとしてフォンテーヌ「水仙十字院」関連6作品（聖遺物『水仙の夢』・『ファントムハンター』、武器『サーンドルの渡し守』・『超越の鍵』・『ルミドゥースの挽歌』・『久遠流転の大典』）および主要10エンティティを追加収録し、フォンテーヌ0件を解消した（※`genshin-db` 上で『静水流転の輝き』は長文本文0文字、『水仙十字の剣』は93文字であることを確認済み）。また第4バッチとしてコース③「テイワット創世記」関連4作品（書籍『竹林月夜（全四巻）』『白姫と六人の小人（全七巻）』、聖遺物『深廊の終曲』『黒曜の秘典』）および主要6エンティティ（月の三姉妹・兹白・スカーク・原初の龍ニーベルンゲン・盗炎の賢者・シュバランケ）を追加収録し、3大フェア棚の収録ラインナップをすべて揃えた。さらに第5バッチとしてスネージナヤ最新実装の6作品（聖遺物『影に沈む幻』『炉炎溶錬の心』『紅血の証』、書籍『スネージナヤ通史（全二巻）』『スネージナヤ通史補編（全三巻）』『蒼星フェイ史略』）および主要6エンティティ（ツァーリ・ベールイ＝モノマフ、アクシーニャ、雄鶏プルチネッラ、隊長カピターノ、アルヴィス大公、イズマイール＋氷の女皇アナスターシャ本名反映）を追加収録し、第6バッチとして創世記・ナド・クライ編4作品（聖遺物『暁の星と月の歌』『天からの贈り物』『月を紡ぐ夜の歌』『長き夜の誓い』）および主要7エンティティ（最初の天の使いネージュフルール、星海の過客、最初の詠月使アイラ、大司祭ルヴィア、最初のライトブリンガー＝ソロヴィ、大盗賊レッド・ミラー、怪僧ロートヴァング）を追加収録した。さらに第7バッチとしてスメール砂漠「三神と花神の遺民」関連7作品（書籍『プシュパの歌（全三巻）』、聖遺物『楽園の絶花』『金メッキの夢』『砂上の楼閣の史話』、武器『赤砂の杖』『聖顕の鍵』『トゥライトゥーラの記憶』）および主要5エンティティ（キングデシェレト・花神ナブ・マリカッタ・マハールッカデヴァータ・鎮霊リルパァール・オルマズド王）を追加収録して、全46作品・58エンティティ・11コースへ拡充した（その後 Phase 4 の組織・歴史・重要用語・地域補完により計 86 エンティティへ拡張済み）。今後はスメール残編（『花海甘露の光』『深林の記憶』・トゥライトゥーラ周辺4武器）や他地域の大型テーマ（レムリア・稲妻鶴観・モンド古代史等）を順次収録し、Phase 3（[`phase3_curation_courses.md`](phase3_curation_courses.md)）の `courses.json` に新規フェア棚として統合する。
